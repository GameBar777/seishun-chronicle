# 青春クロニクル ～君と過ごした1000日間～ 実装仕様（v1）

- 期間：2027/4/5 入学〜卒業式（3年目3月）。1ターン＝1週（約152週）。
- 1週の流れ：電話（週1回・任意。健太／ヒロイン：話す＝傷心ケア／日曜デートに誘う）→平日行動1つ→予定されたシーン（行事・個別イベント・テスト・大会・誕生日・偶然の出会い・噂・デート・自由会話）
- 能力：文系・理系・芸術・容姿・運動・根性・体調・ストレス・モラル・経験値
- 体調不良（体調<20）、ケガ（運動系・体調<35）、スランプ（ストレス>85）
- 部活8種（4月に選択）・バイト6種・服5種
- ヒロイン（すべてオリジナル）：春日ひなた（幼なじみ）、氷室澪（生徒会長候補）、白鷺ゆら（ミステリアス）、速水夏帆（陸上部）、桐生院麗華（お嬢様）、灯野ことは（文学少女）、姫野ルカ（後輩・小悪魔）、黒瀬凛（クーデレ）、宙野しずく（隠し）
- 関係：友好・ときめき・傷心・信頼。段階は 他人→顔見知り→友人→親友→気になる存在→好き→夢中。呼び方は3段階で変わる
- 爆弾：接触が4週以上ないと傷心が溜まる（親しい相手が多いほど早い）。60で点火し、4週以内にケアしないと爆発（関係が大きく下がり、全員に悪い噂）
- ライバル：2年目から。ときめきが低いまま放っておくと、ライバルと付き合ってしまう
- デート：15か所。場所の好み・服装・天気・季節・同じ場所の繰り返し・所持金・3問の受け答え・他のヒロインとの遭遇で評価
- 自由会話：src/sc/chat.ts。意図を分類（挨拶・褒める・勉強・好きな話題・苦手な話題・約束・告白・謝罪・他の女子の話・暴言・プロフィール質問）。約束・好きな話題・傷つけた言葉を記憶し、後で話題にする。1回の交流で3発言まで
- エンディング：隠しトゥルー（しずく）、グッド×8、告白成功、ノーマル、ライバル、友情、進路成功、バッド。進路（国公立・私立・専門・就職）の合否も反映。最後に3年間の振り返り
- 隠し条件：engine.ts の SPECIAL（例：ひなた＝hinata_together と根性100、澪＝mio_speech と国公立合格・モラル70 など）。健太の噂がヒントになる
- 音声：src/sc/voice.ts。Web Speech API（ja-JP）。キャラ別の高さと速さ、感情による変化、「……」で間を取る、名前は読み仮名で読み上げ。設定は全体・ボイス・BGM・効果音・キャラ別の音量、自動再生、地の文の読み上げ、文字送りと声の速さ。BGMと効果音は WebAudio で生成
- セーブ：オートセーブ（localStorage）と、`SEISHUN1:<チェックサム>:<base64>` の文字列でのSAVE/LOAD
- 分量：イベント62件、台詞などの文章 約1,050行（tests/helpers.ts の集計）

## v1.1 アセット・音楽
- 背景: public/img/bg/*.webp（1024w）と *-s.webp（640w、画面幅760px未満で使用）。src/sc/bg.ts が場所・本文から背景を選び、季節・天気・時間帯に応じた canvas パーティクル、視差、色調を付ける。prefers-reduced-motion を尊重。
- 立ち絵: public/img/ch/{id}_{n|h|s}.webp。感情タグ 嬉/照/告/囁→h、哀/怒/嫉→s、それ以外→n。
- 画像はすべて本作のために画像生成AIで作ったオリジナル。既存作品の模倣はしていない。
- BGM: src/sc/audio.ts の WebAudio 逐次合成。title / school（季節で移調）/ date / sad / confession / ending の6曲。
- 主題歌「千日のプレリュード」: 作詞・作曲は本作オリジナル。歌声はなく、楽器演奏に歌詞を同期表示する（タイトル→🎵）。
- サイドイベント: data/hevents2.ts（18本、id末尾 _sN）。エンディング判定の全イベント条件には含めない。

## v1.2 演出強化
- 立ち絵: public/img/ch/{id}_{n,h,s,o,a,b}.webp（640w）＋ -s.webp（360w、max-width:720pxで使用）。o=驚き a=怒り b=照れ。感情→表情: 嬉囁→h 照告→b 哀→s 怒嫉→a 驚→o 他→n。初表示時に全表情をプリロード。
- CG: public/img/cg/{confess,ending,fireworks}.webp。告白（タイトルに「告白」または感情「告」）、エンディング、夏祭りデートで全画面表示→クリック/Enterで本編。
- 音楽: 生成IRのConvolverリバーブ＋コンプ＋シェルフEQ、パン、対旋律（3度下、後半・サビ）、ドラムのフィル／クラッシュ／オープンハット、ベースの動き。主題歌は Aメロ8小節・Bメロ8小節・サビ16小節（インスト、歌唱なし）。
- 音の検証: `node scripts/render-audio.mjs [出力先]`（vite dev を 4637 で起動しておく）で全7曲を OfflineAudioContext で WAV に書き出す。2026-10-31 計測: ピーク −5〜−8dBFS、RMS −26〜−28dB、クリップ0、無音は末尾の残響のみ、中域中心の帯域バランス。
- プレイ時間: tests の playtime モデル（400字/分＋クリック・選択・週メニュー・会話）で1周 約2.3時間（電話・自由会話を多くすると延びる）。

## v1.3 主題歌

## 1. UI / 情報設計

| 放射状コマンド＋左に主人公 | 週の行動を円環で選ぶ。主人公の立ち絵が常に見え「自分の三年間」感 | コマンドに主人公状態（体力・ストレス）を寄り添わせる |

## 2. 好感度・爆弾
- 評価は 普通 / 友好 / ときめき の3段、ハートの色で表現（灰<青<ピンク<赤）。友人（大倉）が評価を教えてくれる。
- 爆弾は3段階：出現 → 点火（脈動・怒り顔）→ 爆発（効果音＋強い画面揺れ、日曜以降のみ）。電話一本で解除できる。
- 示唆：数値より「色と鼓動」で見せる。好感度表示は別ワーカー担当のため本作業では触らない。

## 3. デート／イベント演出
- 良いデートの帰り道に「手をつなぐ」ミニゲーム（天使・悪魔の声、距離、ハートの大きさ）。成功で呼び方が変化。
- ダブルブッキング、追加デート、ワル男（ナンパ撃退）などのデートイベント。
- 示唆：デートは「帰り道」に一場面足すだけで余韻が大きく変わる。

## 4. 告白・エンディング
- 卒業式の日、伝説の樹の下で女の子から告白されるのが基本形。告白前に一拍の「間」（静寂・BGM停止・鼓動）が置かれ、一枚絵で決める。
- 主人公からの告白（告白する勇気）は途中で遮られる／やや苦い結末になることがあり、「待つ」ことに意味を持たせている。
- 伝説の樹以外の思い出の場所で告白するヒロインもいる。
- エンディング後はスタッフロール。結末の格によって長さ・曲が変わる。

## 5. 今回反映したもの（v1.16.0）
1. **エンディングムービー**：ヒロインごとに、見た一枚絵＋思い出の場所の背景をKen Burns（ゆっくりパン/ズーム）でつなぎ、シネマスコープの黒帯・フェード。プレイデータ（部活・デート回数・テスト・大会・進路）から主人公のモノローグを生成。
2. **エンドロール**：キャスト・スタッフ・素材クレジット（魔王魂／OtoLogic／ElevenLabs、docs/audio-credits.md 準拠）がスクロールし FIN。グッドは長尺＋主題歌、ノーマルは短尺、バッドは静かな短尺。SKIP可・もう一度見る可。
3. **告白の挿絵**：9人全員に「卒業式の日、校門で」の一枚絵（自分から告白した場合）を追加。ギャラリー解放対応。
4. **告白の「ため」**：最初の告白台詞の直前に暗転ビネット＋鼓動SE＋1.4秒の間。
5. **イベント見出しのカットイン**：場面タイトルが横からスライドイン。

## 主人公の名前の扱い
名前は端末ごとに違うので音声にできない。画面の文字には名前をそのまま出し、音声は名前を言わない台本で収録した（`scripts/voice/cast.ts` の `spoken()`）。
1. 文頭の呼びかけ（「{名前}くん、」など）は削る。「おい、」「ねえ、」などの前置きは残す。
2. 「……{名前}。」は「……」に、文末の「、{名前}！」は削る。
3. それ以外の場所は、キャラクターごとの二人称に置き換える：ひなた・夏帆・しずく「きみ」、澪・ゆら・麗華・ことは「あなた」、ルカ「センパイ」、凛「あんた」、芽衣「お兄」、健太・真鍋先生「お前」。

音声の行 ID は「話者＋名前を入れる前の台本」のハッシュ（`voiceId()`、16桁）なので、プレイヤーの名前に関係なく同じ音声が鳴る。

## 仕組み
- `scripts/voice/collect.ts` → `lines.json`（ID・話者・台本・感情・収録用テキスト）
- `scripts/voice/gen.mjs` → ElevenLabs で生成（キーは /workspace/.secrets/elevenlabs.env。リポジトリとブラウザには入れない）。生成済みは飛ばすので途中から再開できる。429/5xx は待って再試行。使った文字数は `gen.log`。感情は音声タグ（嬉 [cheerful]、照 [shy]、怒 [angry]、哀 [sad]、驚 [surprised]、嫉 [sulky]、囁 [whispers]、告 [softly]、冷 [coldly]）。
- `scripts/voice/build.py` → QC と変換（モノラル 24kHz 48kbps の mp3、前後の無音を削る）→ `public/voice/<キャラ>/<ID>.mp3` と `public/voice/manifest.json`
- `scripts/voice/spotcheck.py` → ローカルの Whisper で書き起こして台本と比べる抜き取り確認
- ゲーム側（`src/sc/voice.ts`）：台詞ごとに必要になった時点で読み込み、次の2行を先読み。設定に「ボイスON」、音量、キャラクター別音量。iPhone では最初のタップで無音ファイルを鳴らして再生を許可させる。
